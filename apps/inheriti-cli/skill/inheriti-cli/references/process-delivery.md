# Deliver plan fields to a program

Inspect the program's actual input contract and execution location before choosing a mapping. For a trusted local process, `inheriti plans use PLAN_ID [MAPPINGS] -- EXECUTABLE [ARGUMENT ...]` authorises selected fields and starts that exact executable without a shell. Available mappings are `--stdin ASSET.FIELD`, repeatable `--env NAME=ASSET.FIELD`, `--fd N=ASSET.FIELD`, `--temp-file NAME=ASSET.FIELD`, and `--socket NAME=ASSET.FIELD`. Use `--ttl DURATION` when a bounded run is appropriate. Check `inheriti help plans use` for platform limits: sockets and dedicated descriptors are unavailable on Windows. Confirm the exact executable, arguments, fields, destination names, and data path with the user before running it.

For an environment-only child process, `inheriti secrets exec PLAN_ID --env NAME=ASSET.FIELD -- EXECUTABLE [ARGUMENT ...]` uses the same reveal and approval flow. Both commands suppress child stdout/stderr by default because the program might echo a credential. `--output inherit` exposes those logs; use it only with the user's informed choice. Environment variables can be inspected by processes of the same local user. The receiving program can persist or transmit values independently of Inheriti; inspect its configuration, state, and logs before promising a delivery outcome.

An application name is not a command choice. For “use plan X in Terraform,” first identify whether Terraform runs on this computer or in CI/cloud, which input it expects, and whether the user intends a plan, apply, or setup. For a local run that accepts a variable through its environment, a candidate is `inheriti plans use PLAN_ID --env TF_VAR_name=asset.field -- terraform plan`. Inspect the Terraform variable declaration or ask for its exact name before presenting a runnable mapping; never derive `TF_VAR_name` from the credential's description. Use the real declared variable, selector, and exact requested Terraform command. A workload instead needs the [automation flow](automations.md). Do not run `terraform apply` from a request that only says “use.”

`inheriti secrets resolve PLAN_ID --field ASSET.FIELD --allow-plaintext-output` is for a trusted machine wrapper with non-terminal stdout. It emits a raw value, so an agent must not call it into its own tool transcript or redirect it to logs. Prefer `plans use` or `secrets exec` for process delivery.
