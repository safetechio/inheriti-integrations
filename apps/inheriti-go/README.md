# Inheriti® Go

Inheriti® Go is a desktop companion for Inheriti Business. It keeps plan actions close at hand: sign in, choose an organization, create a protection plan, and edit an existing one from the desktop window.

The app is built with Electron and shares authentication and plan behavior with the other [Inheriti Integrations](../../README.md).

On Windows, current Dev, Staging, and Production installers use separate folders. Before upgrading a preview build that used the old shared folder, remove the old preview builds in Windows Installed apps. If Production used the same folder, reinstall Production before installing the current previews.
