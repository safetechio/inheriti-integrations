# Reveal, files, and access lifecycle

Use `inheriti plans show PLAN_ID` to identify field selectors before access. `inheriti plans reveal PLAN_ID [--field ASSET.FIELD ...] [--clipboard-ttl DURATION]` follows the plan's own policy and copies authorised values to the local clipboard without printing them. Repeat `--field` for every requested selector, for example `--field A1.username --field A1.password`; do not silently drop a requested field. An interactive terminal can select one, several, or all fields when `--field` is omitted. In a pipe, the CLI lists available selectors and does not reveal. Name only the fields the user needs; each copied field is authorised and audited separately.

The CLI presents the actual reveal steps: SafeKey Mobile or SafeKey PRO custodian choice when offered, Organisation Key and custodian-share release, authentication/moderator decisions, waiting and reconstruction progress, denial, reconciliation, or a dead-man's-switch stop. The agent explains what the person should do on their device and waits for the CLI outcome; it does not request a share, proof, PIN, or copied value. A rejected or stopped reveal is not a successful delivery. `--clipboard-ttl` conditionally clears unchanged clipboard content while the command remains running; history, synchronisation, shutdown, or forced termination can leave another copy.

For a media asset, use `inheriti plans download PLAN_ID --asset CODE_OR_ID --output NEW_PATH`. Confirm the asset and path. The CLI authorises the copy, writes a new owner-only file, and never overwrites an existing file. In builds with protected copies, the output must end in `.inheriti`; `--open-limit N` is available and defaults to one. `inheriti plans open PATH` opens a saved protected file in Inheriti Workspace when that feature exists. Neither command is a way for the agent to read the content.

Cancellation may leave an operator access request open so a later reveal can resume. Use `inheriti plans abort PLAN_ID` when the user wants to abandon that access and start a fresh one next time; do not abort automatically after every pause. Check plan logs for safe status when the outcome is uncertain.
