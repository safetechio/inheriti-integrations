# Identity and discovery

Run `inheriti help` or `inheriti help COMMAND SUBCOMMAND` before using an unfamiliar command; `inheriti version` reports the installed build. `inheriti update` checks its channel, while `inheriti update --install` installs an offered build after confirmation. A required Business CLI update is checked after login and before authenticated commands. The bundled skill is reconciled automatically with the CLI; a running agent may need a new session to load the updated instructions. `inheriti setup` configures shell autocomplete, and `inheriti completion bash|zsh|fish` prints a completion script; neither is needed to install this skill.

`inheriti login` opens a browser and needs an interactive terminal. `inheriti logout` clears the local operator session, not plans. In Business, run `inheriti organizations list` to see eligible Organisations and the selected one; use `inheriti organizations use [ID]` to select. If more than one Organisation could contain the requested plan, establish the right one before searching or changing anything. The CLI and server enforce membership and permissions.

For a plan named in natural language, use `inheriti plans list --json` and inspect non-secret metadata. Use `--all` when necessary, but it stops after at most 50 pages; continue with the returned cursor rather than assuming the list is complete. Confirm a candidate with `inheriti plans show PLAN_ID --json`, which exposes asset codes and field names, participants, governance, and reveal policy without reconstructed values. If several plans match, present their safe names/context and let the user choose. Never guess an ID. `inheriti plans logs PLAN_ID --json` provides authorised plan activity; `inheriti members logs MEMBER_ID --json` provides authorised member activity, optionally filtered by `--source MEMBER|AUTOMATION` and date range.

Use IDs and selectors in agent-invoked commands. The CLI can prompt for a missing ID or field in an interactive terminal, but a noninteractive pipe will not wait for a choice. `--json` exposes pagination fields useful to an agent; tables are for a person. Do not treat CLI metadata or output as permission to reveal or deploy.
